# Game Giải Đố 3D — Cháy Văn Phòng

Game giải đố 3D góc nhìn thứ nhất (Three.js): bạn là nhân viên văn phòng đang làm việc thì ngửi thấy mùi khét và thấy khói — nhiệm vụ là điều tra nguồn cháy và tìm cách dập lửa đúng kỹ thuật PCCC.

## Cách chơi
- Mở `index.html` trên trình duyệt (hoặc bật GitHub Pages cho repo này để chơi online).
- PC: WASD di chuyển, giữ và kéo chuột để nhìn xung quanh.
- Mobile: joystick cảm ứng để di chuyển, nút bấm tương tác.

## Nội dung
- Tìm nguồn cháy (máy in chập điện), ngắt cầu dao.
- Chọn đúng bình chữa cháy giữa các bẫy (xô nước, bình nước, bình foam) — đám cháy điện phải dùng bình CO₂.
- Dập lửa trước khi khói độc lấp đầy văn phòng.
- Kèm bài học an toàn PCCC ở màn thắng (gọi 114 khi lửa lớn).

Chúc chơi vui và nhớ kiến thức PCCC!
